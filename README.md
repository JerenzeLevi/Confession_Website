A minimalist, aesthetic "Yes or No" confession site. Designed to ask the big question with a little bit of digital charm.

## ✨ Features
* **Interactive UI:** A simple, clean interface for the "crush" experience.
* **Automated Notifications:** When they click **YES**, their response is sent directly to your inbox.
* **Responsive Design:** Works on both desktop and mobile.
* **Aesthetic Vibes:** Built with smooth CSS transitions and minimal JS.

## 🚀 How to Use & Customize

> [!IMPORTANT]  
> To receive answers, you **must** have a [Formspree](https://formspree.io/) account.

1.  **Clone the Repo:** Download or fork these files to your local machine.
2.  **Setup Formspree:**
    * Create a new form on Formspree.
    * Copy your unique **Endpoint ID**.
    * Replace the placeholder URL in the `action` attribute of your HTML form.
3.  **Personalize:**
    * Change the text in `index.html` to fit your confession.
    * Swap out GIFs in the each html.
4.  **Publish:** Host it on GitHub Pages, Vercel, or Netlify.
